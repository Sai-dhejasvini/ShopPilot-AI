# Project Report: ShopPilot AI — Autonomous Agent for Smarter Commerce

**Author:** Sai Dhejasvini  
**Track:** AI Growth & Agentic Commerce  
**GitHub:** [Sai-dhejasvini/ShopPilot-AI](https://github.com/Sai-dhejasvini/ShopPilot-AI)  

## 1. Executive Summary
ShopPilot AI is a portfolio-ready autonomous commerce web application built from scratch to demonstrate full-stack AI engineering, deterministic data retrieval, explainable recommendation systems, and growth analytics.

## 2. Key Technical Innovations
1. **Separation of Reasoning and Data Access:** Enforces Grounded AI Responses by strictly forbidding the LLM from generating product data out of its training weights.
2. **Transparent Multi-Factor Scoring Model:** Employs configurable weight matrices and exponential budget decay functions to provide explainable recommendation rationales.
3. **Session-Aware Contextual Memory:** Resolves conversational follow-ups without storing sensitive user data.
4. **Actionable Growth Intelligence:** Uncovers catalog inventory gaps (e.g. demand for OLED laptops under ₹65k) directly from user query patterns.
